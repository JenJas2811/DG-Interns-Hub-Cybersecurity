# DG-Interns-Hub-Cybersecurity
DG Interns Hub – Week 3 Cybersecurity Assessment
Project Title

Final Mini Security Assessment – Network Discovery, Traffic Analysis and Security Hardening

Objective

To perform a basic security assessment of an authorized lab network by identifying active devices and exposed services, analyzing network traffic, identifying security weaknesses, and applying basic security-hardening measures.

Lab Environment
Operating System: Kali Linux
Environment: Authorized Virtual Lab
Network: Private/Internal Lab Network
Target: Authorized lab machine(s)
Tools Used
Nmap – Network discovery, port scanning, and service identification
Wireshark – Network traffic and packet analysis
Kali Linux – Security testing environment
Tasks Completed
Performed network discovery to identify active devices.
Scanned hosts to identify open ports and services.
Analyzed TCP and DNS traffic using Wireshark.
Investigated SYN, SYN/ACK, and RST packets.
Performed a basic vulnerability/security assessment.
Identified potential security weaknesses.
Applied basic security-hardening measures.
Compared the network security state before and after hardening.
Key Findings

The assessment identified several areas that could increase the network attack surface:

Unnecessary open ports
Unnecessary network services
Excessive network exposure
Weak or overly permissive firewall configuration
Potentially insecure or unnecessary communication

These findings were reviewed based on their potential security impact.

Security Improvements

The following security improvements were applied:

Disabled unnecessary services.
Restricted unused or unnecessary ports.
Improved firewall access control.
Reduced unnecessary network exposure.
Allowed only required network communication.
Before/After Results
Area	Before Hardening	After Hardening
Unnecessary Services	Accessible	Restricted/Disabled
Unused Ports	Accessible	Restricted/Closed
Network Exposure	Higher	Reduced
Firewall Access	Less Restricted	More Controlled
Attack Surface	Larger	Reduced

The comparison showed that applying basic security-hardening measures can reduce unnecessary network exposure and minimize the attack surface.

Conclusion

This assessment provided practical experience in performing a basic network security assessment using Nmap and Wireshark. It helped demonstrate how network discovery, port scanning, packet analysis, vulnerability identification, and security hardening can be combined to improve the security of an internal network.
